# Personal Finance Frontend

This is the frontend for the Personal Finance Dashboard, built with React and Vite.

## Tech Stack
- **React**
- **Vite**
- **Tailwind CSS**
- **React Router**
- **Axios**
- **Context API**

## Features
- **Dashboard**: Overview of transactions, budgets, and goals.
- **Transactions**: View and manage financial transactions.
- **Budgets**: Set and monitor budget limits with progress bars.
- **State Management**: Uses React Context API for global user state.

## Installation Steps
1. Navigate to the `frontend` directory.
2. Run `npm install`.
3. Create a `.env` file with `VITE_API_URL`.
4. Run `npm run dev` to start the development server.
